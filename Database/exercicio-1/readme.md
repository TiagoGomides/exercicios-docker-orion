# Exercício 1 — Banco Relacional (SQL Básico)

### Objetivo
Aprender os comandos básicos de SQL para **Definição (CREATE TABLE)** e **Manipulação (INSERT, SELECT)**.


## Descrição
Neste exercício, você criará tabelas, definirá colunas e chaves, e inserirá alguns dados de teste.

**Passos:**
1. Criar a tabela `cursos`
2. Criar a tabela `alunos` com chave estrangeira (`curso_id`)
3. Inserir dados nas tabelas
4. Validar as restrições e realizar consultas

## Criar tabela `cursos`
A tabela `cursos` deve conter:
- `id` — Chave primária numérica  
- `nome_curso` — Texto (nome do curso)

```sql
CREATE TABLE cursos (
  id          INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nome_curso  VARCHAR(120) NOT NULL
);
```

## Criar tabela `alunos`
A tabela `alunos` deve conter:
- `id` — Chave primária
- `nome` — Texto
- `email` — Texto único
- `curso_id` — Número inteiro vinculado à tabela `cursos`
```sql
CREATE TABLE alunos (
  id        INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nome      VARCHAR(120) NOT NULL,
  email     VARCHAR(150) NOT NULL UNIQUE,
  curso_id  INTEGER NOT NULL,
  CONSTRAINT alunos_curso_fk
    FOREIGN KEY (curso_id)
    REFERENCES cursos (id)
    ON UPDATE CASCADE
    ON DELETE RESTRICT
);
```

## Consulta dos itens adicinados (`alunos` + `cursos`)


![Trazendo dados na tabela alunos](../assets/exercicio-1/Trazendo%20apenas%20alunos.png)

- `cursos`
```sql

```

![Trazendo dados na tabela cursos](../assets/exercicio-1/Trazendo%20apenas%20cursos.png)

- Consulta com `JOIN`
```sql
SELECT a.id, a.nome, a.email, c.nome_curso
FROM alunos a
JOIN cursos c ON c.id = a.curso_id
ORDER BY a.id;
```
